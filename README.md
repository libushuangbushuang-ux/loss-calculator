# 损失比例计算器

这是我的第一个 GitHub 项目：一个中文计算工具。

## 如何使用

下载 index.html，用 Safari 打开。输入原金额和剩余金额，点击“计算损失”。无需安装软件，也无需联网。

示例：原金额 10,000，剩余金额 7,500，损失金额为 2,500，损失比例为 25%。

剩余金额高于原金额时，显示增加金额和增加比例。

## 如何上传到 GitHub

1. 打开 https://github.com/new 。
2. 在 Repository name（仓库名称）填写 loss-calculator。
3. 选择 Private（私有）。其他选项保持默认，点击 Create repository（创建仓库）。
4. 新仓库页面上点击 uploading an existing file（上传已有文件）。
5. 将 index.html 和 README.md 两个文件拖进去。
6. 在修改说明中填写“添加我的第一个计算器”，点击 Commit changes（提交更改）。

上传成功后，仓库文件列表里会出现这两个文件，下面会显示这份说明。

注意：将 HTML 上传到仓库是保存代码，并不会自动变成可在线访问的网站。现在可以先在本机打开使用。

## 下一次可以做什么

把“损失比例计算器”改成“我的金额计算器”，再次上传 index.html。GitHub 会留下前后两次修改的记录。

## 隐私

输入的金额只在当前页面计算，不会上传或持久保存。
